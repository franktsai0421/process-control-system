# 04 UI、互動與驗收

`02_UI設計/IPQC-AB_目前UI預覽.html` 是可互動版面示意；`IPQC-AB_主頁示意.svg`、`IPQC-AB_項目彈窗示意.svg` 是快速閱覽圖。正式開發以 repo 的 FQC/品質資料後台現行元件、設色及權限為準。草圖的本機照片網址和畫面按鈕提示**沒有**正式後端持久化能力。

## 畫面重點

- 頂部 IPQC-AB線入口，版本卡左顯示版本／狀態（舊測試送審入口已移除），右顯示版本／草稿下拉、「儲存草稿」、「送出審核」。操作歷程與報錯／待補分兩個收合區，待補可前往項目設定。
- 錯誤代碼列表可查看全文、新增、修改、刪除；點代碼顯示其檢查項目列表。項目列表顯示**項目啟用**、目視／設備及設備圖示、共用頻率、多張照片縮圖、查看／修改／刪除。新增與修改用彈窗。
- 項目彈窗設定項目標準、單一「檢查方式圖片」編輯區（保留兩個既有照片陣列）、檢查方式敘述、目視／設備、項目啟用與頻率。初次匯入預設目視。照片可多張，清單有縮圖，相簿可切換；圖片選填。包含產品以核取方塊及編碼／名稱卡片對齊呈現；彈窗本體獨立捲動，儲存／取消固定可見。
- 矩陣行是檢查項目、列是中控合格候選產品；勾選＝包含，未勾＝不包含。未涵蓋產品只展示，沒有額外分配按鈕。項目停用後原關聯保留，但不算生效或覆蓋。
- 不顯示「與 FQC 共用」、檢具與測試設備標準引用專區、Excel 匯入／匯出、審核預覽、下方重複的版本紀錄。

## 驗收清單

1. 切換 A/B 線、群組、工段，只展示相符的中控候選產品；找不到產品時明確展示原因，切換下拉不跳頁／不重置卷軸。
2. D 錯誤代碼、F 檢查項目可查看及彈窗增改；自動接碼、刪除不重用，僅符合資料引用規則時可刪除。
3. 草稿勾矩陣、獨立關閉項目、修改頻率及照片後，重新登入仍可看到；未送審不影響生效版。
4. 選設備沿用 FQC／IQC：生效版本且已啟用即可選，類別／子類別／規格群組及搜尋可組合過濾；顯示不再區分「獨立／候選」，原群組 ID 與來源名稱保留。校正、來源確認不額外擋本頁選擇，檢具頁原有校正規則不變。項目清單分開顯示啟用、設備縮圖／編號／名稱與頻率，設備卡可開啟唯讀資訊並逐項反查引用；既有歷史關聯保留。設備替換可勾選 AB 標準並確認移轉至所屬線別／群組草稿，以群組＋項目穩定 ID 防止混寫；只改設備關聯，照片、標準與其他人工設定保留，待審／測試待審只建立待處理紀錄，不更新生效版本。移轉僅需一般確認，會提示將取代的草稿人工選擇，不另設覆蓋核取方塊；資料變更需重新核對確認，寫入仍有備份及 revision 保護。
5. 同項目標準照片和檢查方式圖片各可多張，清單點縮圖開全相簿；草稿、退回及正式核准版都能正確載入。
6. 該錯誤代碼的全部候選產品都納入覆蓋提醒，包含完全未有有效 YES；不阻擋送審／核准，修正入口導向對應矩陣。
7. 依[最新 IPQC 政策](../../docs/specs/current/IPQC_POLICY.md)驗收三項待補非阻擋、非法格式／引用／標準等原限制仍阻擋；不使用已移除的測試送審入口。
8. 重跑同一來源不重複建立錯誤代碼、項目、產品關聯或照片；正式環境原有 FQC／IQC 功能保持正常。
