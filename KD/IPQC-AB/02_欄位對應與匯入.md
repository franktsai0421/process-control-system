# 02 欄位對應與初次匯入

**來源**：`01_最新資料/IPQC_CHUAN_29092026_V.xlsx` 的 `IPQC` sheet；固定 SHA256 見 README，第 1 列為表頭，第 2–1462 列為資料。A–T 按實際合併區域完整展開。合併 H／H:I 儲存格的整份多行產品清單適用於每個所涵蓋來源列，不能依行數分攤成一列一品號。保留文字品號（數值欄按零位格式保留前導零）、來源列號和產品合併區域。公式不猜測快取結果。`RA_SOAT_NHOM` 與 U/V 不匯入。

| Excel | 解析與目標欄位 | 注意 |
| --- | --- | --- |
| A 產線 | line A/B | `LINE A`／`LINE B` 正規化為 A／B；比對 AB 主資料。 |
| B 產品群組 | group | 比對同線別的中控類別；未知群組列待核對，不自動建類別。 |
| C 製程 | stage | 比對線別與工段管理及產品工段路線；`PACKING` 按來源保留，後端代碼映射依既有主資料確認。 |
| D 錯誤代碼 | error_code | 父項；與 A/B/C 的線別群組工段一致；值保留原碼。 |
| E 檢驗項目 | error_name | 依來源欄位實為錯誤代碼的名稱，如 Kiểm tra zoong；勿當成每一列標準。 |
| F 檢查編號 | sourceItemCodes / assigned item.code | D 的子項；新版同一来源號可能有不同標準，必須拆分；不是唯一項目身分。保留既有身分與編號，新項後端接號、不重用已用或刪除碼。 |
| G IPQC 項目標準 | standard_text | 項目層級越文標準；保留原文。 |
| H 產品名稱／代碼 | item_product relations | 同儲存格多行，逐行拆成第一個空格前的產品編碼與後續來源名稱；逐一核對主資料。 |
| I | 無資料 | 勿當成產品名稱，與舊 v2 欄位結構不同。 |
| J 檢查方式敘述 | method_text | 本來源全空；對已啟用、有勾選且主資料匹配的項目擋正式送審。 |
| K 檢查方式圖片 | method_images | Excel 無圖片；新系統可多張，選填。另新增標準照片集合，來源 Excel 無此欄。 |
| L 檢驗工具／設備 | tool_source | 原文稽核保留；**初次匯入一律設目視且不綁檢具**。以後在網頁編輯時仍可切換設備並從現有清單選擇。 |
| M 檢驗方法 | inspection_method_source | 保存來源文字以供參照；不與 J 檢查方式敘述混淆，也不臆造 J。 |
| N 頻率 | frequency_source | 原文保留；只在可確定時轉 IQC 頻率規則，`1` 和組合文字列人工確認。 |
| O 是否啟用 | item_enabled | 本來源均 YES；這是檢查項目啟用，不是矩陣勾選，也非檢查方式。 |
| P/Q/R/S/T | version / changed_at / change_reason / creator / notes | 來源資訊保留供稽核；別直接將舊版本值當新系統正式審核版。 |
| U/V | 原表統計欄 | 不作檢查項目或主資料匯入。 |

四份 CSV 每次由唯一新版 Excel 和當前生效 Local catalog 重新生成，不作匯入輸入。只有精確符合線別＋群組＋產品＋工段路線的 H 欄關聯才可進草稿；同筆所有不符原因均保留。無有效關聯的來源項目不建立空項。O 是項目啟用，不代替矩陣或檢查方式；沒有標準／频率產品例外。標準相同但共用欄位不同則暫緩、列出衝突，不取第一筆或拼接。

## 建議執行順序

1. 開發者按任務查 repo 實際主資料、群組／路線、FQC／IQC 的設備連動、版本流程與圖片儲存，輸出對應位置與矛盾，不改資料。
2. 用正式 Excel 解析器對照即時生效 Local catalog；不使用舊 CSV／舊統計。產生來源列號、所有排除原因、不同標準拆分、相同標準基本資料衝突與未對應群組清單。
3. 項目保存 `sourceImport`：來源內容穩定 key、SHA、來源編號、來源基本欄位 baseline 和前次 key。身分確認必須有錯誤碼＋標準＋來源對應，不能只憑 itemCode；sourceRows 不是重編號依據。已匯入舊稽核報告僅用于重建上一批 baseline，不能作新版來源。三方合併保留人工標準、敘述、頻率、啟用與關聯衝突，照片／人工設備永不搬移；歸屬不唯一則保留原項並暫緩來源項。來源欄位與合法非人工關聯更新，重跑或 Excel 排序改變不追加項。
4. 寫入前備份受影響 Local D1/R2 和關聯；先在還原副本驗證，然後只增量合併 Local port 3000 群組草稿，不清空、不送審、不更新生效版本、不寫 Staging／Production。新版未出現且可確認為無人工修改的匯入項僅軟刪 `deleted:true`，來源不明／人工修改保留。舊照片及歷史引用不物理刪除。
5. 人工檢查示例 `A-BORUAXE1021-ASSY-L1-01` 與多產品清單，再驗證矩陣、照片、設備、草稿重開、測試送審永不生效與正式阻擋規則。

實際匯入結果見 03／08；每次重跑必須重新核對來源 SHA 和當前 Local 主資料與修訂，不直接提供正式 DB SQL。
