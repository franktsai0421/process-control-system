# IPQC-AB 線交接包

用途：供 AG 先做唯讀掃描，供 Codex 在現有中控／品質系統專案中實作 UI、資料庫與 Excel 匯入。這裡的 HTML 是操作草圖，不是已接上資料庫的網站；Excel 目前尚未匯入正式資料庫。

**UI 定案（2026-09-26）**：畫面設於「品質系統 → 資料後台 → IPQC-AB線」，使用現有資料後台的深綠側欄、淺色底、白色卡片及橘紅色送審按鈕。`IPQC_AB_UI_草圖.html` 展示版本／草稿、操作歷程、報錯／待補、篩選、錯誤代碼、檢查項目及矩陣；按鈕與彈窗可逐一檢查。**頁面不設 Excel 匯入、匯出或下載範本功能**；v2 Excel 仍供最初的離線資料整理與隔離測試匯入，後續資料在網頁草稿中修改。

**2026-09-26 後續 UI 修正**：依檢具與測試設備頁位置，版本／草稿卡下方分設「操作歷程」與「報錯／待補」收合列，後者包含逐筆「前往設定」；下方不再放獨立待補功能區、審核預覽或底部版本紀錄。未涵蓋產品只顯示名單。錯誤代碼有「查看完整內容」。檢查頻率採 IQC 已定的「按批次／依樣品」和「按時間」規則，各項目保留至少一條；按批次可選 AQL、固定件數、批次數量、自訂，按時間可選週、月、季、半年、年、自訂。草圖的新增、修改、刪除及矩陣變動會儲存在**開啟它的瀏覽器本機**；這僅用於檢查 UI 流程，不是正式資料庫或跨使用者資料保存。

**最新操作決定**：矩陣只用勾選 YES（包含）／未勾選 NO（不包含），不設移除關聯；原始 NO 保留於匯入稽核紀錄。頻率在檢查項目設定，該項目所有勾選產品共用，不設產品頻率例外。檢查項目另外可存取多張標準照片，與檢查方式圖片分開；「查看」提供縮圖和點開大圖。草稿版本卡依 `參考_草稿版本按鈕配置.png`：左側版本資訊，右側查看版本／草稿、儲存草稿、送出審核；測試送審獨立放在左側次要連結，保留既定測試流程。

## 掃描順序

1. `IPQC_AB_實作與匯入交接.md`：實作邊界、欄位對應、匯入檢查、驗收。
2. `IPQC_AB_討論框架.md`：此前逐項確認的詳細業務規則；與交接摘要有衝突時，先回報具體差異，不自行改業務決策。
3. `IPQC_CHUAN_AB_編碼調整_v2.xlsx`：唯一匯入來源；`IPQC` 是明細，`THONG_KE_THIEU` 是原附統計，不匯作明細。不得回頭匯入未調整編碼的原始檔。
4. `FQC_版面參考_品質入口.png`、`FQC_版面參考_資料列表.png`、`IPQC_AB_UI_草圖.html`、`IPQC_草圖_手機預覽.png`：沿用 FQC 真實 UI 的色系、區塊和版型；手機截圖用於討論窄螢幕呈現。最新草圖可點開各功能與彈窗，示意操作只儲存在目前瀏覽器，不寫入正式資料庫。
5. `參考_檢具設備_版本與操作歷程.png`、`參考_檢具設備_上方資訊區.png`、`參考_IQC_頻率規則.png`、`參考_草稿版本按鈕配置.png`：2026-09-26 的畫面參考，分別對照頂部版本卡／歷程及 IQC 頻率表單。
6. `IPQC_橘色待補參考.png`：Excel 橘色待補位置的視覺參考。`版本確認平台_品質系統資料庫.png`：測試與正式審核單的目標分頁。其餘既有中控系統截圖保留原檔名以對照主資料。
7. `IPQC_AB_AG_掃描提示.md`、`IPQC_AB_Codex_執行提示.md`：可直接貼給兩個工具的工作指示。

## 環境與權限

本包沒有程式倉庫、D1/R2 結構或 AB 主資料的即時快照；它提供資料與已確認的規則。AG/Codex 必須掃描目前倉庫及目標測試環境才可決定 migration、API 與主資料對應。先做可審核的匯入預覽和差異報告，未匹配群組／產品逐一解決後，寫入隔離草稿或測試環境；不得假設群組名稱完全匹配，不得直接覆蓋已生效資料或正式資料庫。
