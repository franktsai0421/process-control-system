# IPQC-C UI 與雙語規格

入口為「資料後台 → 品質系統 → IPQC-C」，沿用品質系統側欄、卡片、按鈕及共用語言切換。**預設越文 `vi-VN`**，中文 `zh-TW` 為對照。參考 `UI/UI_設計圖總覽_越南文.html` 與 `UI/UI_設計圖總覽_中文.html` 的同序 19 張畫面。總覽可獨立開啟並往下捲，不依賴額外圖檔或腳本。

## 網站功能

1. 頂部顯示生效版／草稿、修改人、開始修改、儲存草稿及送審。唯讀時不出現列新增／修改／刪除。**不顯示 Excel 匯入、匯出、下載範本、上傳及差異預覽按鈕**，也不在這個頁面建立使用者可操作的 Excel 流程。
2. 依產品代碼或名稱搜尋既有 C 線產品；支援越文聲調輸入法組字，不重複字元。產品選取後顯示現行唯讀製程路線，名稱由上游主檔提供，不能在 IPQC-C 改產品或工段。
3. 左側錯誤代碼列表顯示代碼、名稱、項目數及各列操作。選中代碼後右側才顯示檢查項目及其自身操作；兩層表單分開。
4. 錯誤代碼：所屬產品及工段唯讀、系統發號唯讀、錯誤名稱、備註、修改理由；有子項目時不能單獨刪除，整組刪除列出影響。
5. 檢查項目：所屬及編號唯讀、原文檢查標準、獨立的標準啟用與 CPK 啟用、檢查方式、網站多張圖片、工具／設備、頻率及備註（來源方法、舊理由保留；不要求重建已移除欄位）。圖片可在文字間插入和排序。刪除、草稿、歷史保留已發號及既有檢查紀錄。
6. 舊資料的空欄顯示「Chờ bổ sung／待補」，修改其他欄位時不補造值；新項目的標準等既有要求保留；檢查方式敘述、頻率及涵蓋依[最新 IPQC 政策](../../docs/specs/current/IPQC_POLICY.md)僅提醒、不阻擋送審／核准；舊「不適用」選項已在後續UI移除，原欄位保留，不能藉此繞過現行品質驗證。工具依[品質設備](../../docs/specs/current/QUALITY_EQUIPMENT.md)選現有設備，舊工具文字照原文保留。
7. 草稿可登出後續編；以[單一共享草稿](../../docs/specs/current/SHARED_DRAFT.md)及revision／相依防護處理並行修改；舊個人草稿與三值衝突方案不再適用。送審後鎖定，發回或有權限撤回後可再編輯；版本確認平台獨立提供撤回，不依賴核准／發回權限；歷史版唯讀。手機依產品、工段、錯誤代碼、項目逐層導覽，編輯用全頁表單。

## 語言與資料規則

| 類別 | 越文版（預設） | 中文版 | 儲存規則 |
| --- | --- | --- | --- |
| 導覽、按鈕、欄位標籤、驗證及送審訊息 | 越文 | 繁體中文 | UI 字典對同一欄位鍵切換，不另建兩份標準。 |
| 產品名稱、錯誤名稱、檢查標準、方法與頻率來源文字 | 顯示越文原文 | **仍顯示越文原文**，可附中文欄位標籤 | 不自動翻譯，不覆蓋來源。日後如需中文業務內容，新增經人工審核的獨立欄位。 |
| 單位、公差、符號、換行、編號 | 原樣顯示 | 原樣顯示 | 按原值保存，無語言版本的雙份編號。 |
| 既有上游產品／工段名稱 | 從既有主檔讀取當前顯示值 | 從主檔讀取當前顯示值 | 若主檔無中文，不臆造名稱。 |

語言切換保留目前產品、工段、草稿及捲動情境；唯讀與編輯權限不因語言改變。越文輸入框使用 Unicode，搜尋以代碼和越文名稱支援帶／不帶聲調匹配，儲存原始文字。確切字串見 `UI/畫面索引與雙語欄位.md`；依現有系統 i18n 方式接入，不另建不一致的全域翻譯機制。
