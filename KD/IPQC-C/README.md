## 資料基線與邊界

正式來源共有 **862 項、81 個產品**，由原表 1,087 項排除找不到 C 線產品的 225 項，並按已確認工段同步 E/G 編號。2026-09-25 工作區主檔快照下，862 項均對應產品路線，E/G 各 862 個且不重複；啟用標準 826、停用 36、CPK 啟用 62、啟用但頻率空白 29。這是快照，不代表網站當前已同步。

產品與製程路線只讀既有 C 產線主檔。網站管理兩層資料：錯誤代碼及其檢查項目，經共用草稿、送審和版本確認後生效。使用者日常新增及修改直接在網站表單完成。越文原始標準、產品名、工具、方法、頻率保留原值與換行，切換中文介面時不憑空翻譯標準內容。

開發者首次建資料前須依當時生效主檔與既有編號重新核對，記錄差異與衝突。原來源缺列不等於刪除網站舊資料；若已發號有歷史引用，不得直接換號。首次建資料不透過 IPQC-C 網頁操作，正式環境執行仍依當次任務與既有發布程序。
