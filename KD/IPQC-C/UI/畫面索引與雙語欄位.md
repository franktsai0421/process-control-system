## 固定詞彙對照

| 欄位／動作鍵 | 越文（預設） | 中文 |
| --- | --- | --- |
| `productSearch` | Tìm mã hoặc tên sản phẩm | 搜尋產品代碼或名稱 |
| `processStage` | Công đoạn | 工段 |
| `errorCode` | Mã lỗi | 錯誤代碼 |
| `checkItem` | Hạng mục kiểm tra | 檢查項目 |
| `checkStandard` | Tiêu chuẩn kiểm tra | 檢查標準 |
| `standardEnabled` | Bật tiêu chuẩn | 啟用標準 |
| `cpkEnabled` | Bật CPK | 啟用 CPK |
| `checkDescription` | Mô tả cách kiểm tra | 檢查方式敘述 |
| `toolEquipment` | Dụng cụ / thiết bị kiểm tra | 檢查工具／設備 |
| `testMethod` | Phương pháp kiểm tra | 檢驗方法 |
| `frequency` | Tần suất kiểm tra | 檢驗頻率 |
| `note` | Ghi chú | 備註 |
| `changeReason` | Lý do thay đổi | 變更理由 |
| `saveDraft` | Lưu bản nháp | 儲存草稿 |
| `submit` | Gửi duyệt | 送出審核 |
| `returnDraft` | Trả lại bản nháp | 退回草稿 |
| `missingLegacy` | Chờ bổ sung | 待補 |
| `notApplicable` | Không áp dụng | 不適用 |

## 內容語言與產品名稱

表中翻譯的是**網頁介面字串**。來源 Excel 的產品名稱、錯誤名稱、檢查標準、方法、頻率、工具與敘述保留越文原文；中文介面不把其內容機器翻譯為中文。設計圖內的示例內容用於排版，實際畫面讀現行主檔與生效版本。

網站不提供 Excel 匯入、匯出、下載範本、上傳或差異預覽。首次資料建置由開發流程使用越文 Excel 來源，按[首次資料建置](../IPQC-C_首次資料建置與驗收.md) 映射狀態碼。
