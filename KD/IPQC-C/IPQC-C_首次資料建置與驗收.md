# IPQC-C 首次資料建置與驗收

這是**開發／部署時一次性資料建置規劃**，不屬於網站頁面的 Excel 匯入／匯出功能。日後使用者在網站表單維護標準，透過共用草稿、送審和版本確認生效。

## 來源及語言

唯一預定來源為 `資料/正式匯入/IPQC-C_越文首次建置來源_862筆.xlsx` 的 `IPQC_LINE_C!A:P`，資料列 2–863。此檔的**欄名、文字與狀態為越文**；產品代碼保持文字，原越文、Unicode 聲調、符號、公差、單位、換行與空值都保留。A–D 已從原檔合併頂格逐列展開，沒有需要網站使用者處理的合併格。`資料/核對參考/IPQC-C_原始中越表頭_862筆.xlsx` 保留原始中越欄名與狀態供追溯，不作實際建置來源。

| 欄 | 用途 | 首次建置處理 |
| --- | --- | --- |
| A–D | 產線、產品代碼、越文產品名、工段 | 已逐列展開；B 代碼當文字；用 B/D 核對當時生效主檔，C 原文僅供核對，不覆蓋主檔。 |
| E–G | 錯誤代碼、越文錯誤名稱、項目編號 | 保留原編號、驗唯一及 G 的父代碼；已發號及歷史引用先列衝突。 |
| H | 越文標準文字 | 原文保存；不能憑中文介面要求翻譯。 |
| I | CPK 標記 | 越文 `Bật` → true、`Không` → false；其他值報錯。網站介面顯示 `Bật CPK／啟用 CPK`。 |
| J | 越文檢查敘述 | 原文與換行保存。 |
| K | 圖片預留 | 不建圖片資產，不以空值刪除網站已存在圖片。 |
| L–N | 工具、越文方法及越文頻率 | 逐字保存，未知設備或選項列報；不自動猜測相近選項。 |
| O | 標準啟用 | 越文 `Có` → true、`Không` → false；與 I 的 CPK 分開。網站越文介面顯示 `Đang dùng／Tạm ngưng`。 |
| P | 備註 | 原文及空值保存。 |

來源基線：**862 項、81 產品，E/G 各 862 唯一，CPK 啟用 62，標準啟用／停用 826／36**。其中停用且標準空白 36 項、啟用但頻率空白 29 項，原值保留並列報。K/P 空白。53 個產品的 Excel 名稱與 2026-09-25 工作區 C 線主檔字面不同；用代碼關聯，不改主檔名稱。原表排除的 225 項僅供追溯，不能自動建入。

## 開發者操作與驗證

1. 在安全環境讀取全越文來源，對照**執行當時**生效產品、工段路線、已發 E/G 及檢查紀錄，產出逐列核對報告：來源行、代碼、工段、新增／已存在／失配／衝突與理由。報告由開發流程查看，**不在 IPQC-C 網頁提供 Excel 預覽畫面**。
2. 確認映射、衝突與歷史影響後，以可重試且不重複寫入的建置程序處理。來源缺列不刪除網站既有資料；有舊號引用不能暗中改號。依既有 migration 與發布流程執行，不能直接把本包當 Production 更新命令。
3. 驗證 C 線產品及路線、862 項基線差異、空值保留、越文聲調與換行、CPK／標準兩個獨立狀態、圖片不被清除、已發號不重用。重試不重複建列；實際有效筆數以現行主檔重新計算並報告。
4. 驗收網站：越文預設、可切換中文標籤且業務越文原文不變；導覽與手機、兩層 CRUD、草稿重登入、revision／相依防護、送審鎖定、退回、生效及歷史可追溯。**全站 IPQC-C 入口與頁面均無 Excel 匯入／匯出／下載範本操作。**
